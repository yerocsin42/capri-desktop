If macOS won't open Capri

This Mac build isn't notarized by Apple yet, so macOS blocks it the first time.

1. Drag Capri into your Applications folder.
2. Open Terminal (press Cmd + Space, type Terminal, press Return).
3. Paste this line and press Return:

   xattr -dr com.apple.quarantine /Applications/Capri.app

4. Open Capri again.

That line only removes the "downloaded from the internet" flag from Capri. Nothing else on your Mac changes.

If you'd rather not use Terminal: try to open Capri once, then go to System Settings > Privacy & Security, scroll down and click Open Anyway. If macOS says Capri "is damaged", that button won't appear, so use the Terminal line above.
